# 儿科临床药典 V1.3 — 呼吸、消化与住院输液模拟专版

> **重要声明**：所有病例均为原创、虚构教学病历，非真实患者记录；评分标准为本项目教学规则，尚未经过中国儿科专家逐例签审。不得将模拟治疗选择当作真实患儿处方或输液医嘱。

## 重点升级（基于 V1.2 继续扩展）

- 新增 **36 个独立临床教学主场景，每个 4 个情境变化，共 144 份新病例**，保留 V1.2 原有 13 例，总计 157 份。
- 新增呼吸48份：12种主场景 × 4个情境；消化48份：12种主场景 × 4个情境；住院输液48份：12种主场景 × 4个情境。
- 住院输液病例包括：入院情况、首次/日常病程、护理观察、模拟检验、出入量、待审核静脉医嘱，以及班次交接与三项医嘱通过/退回判断（含扣分反馈）。
- 评分覆盖问诊、查体、检查、诊断、药品策略、处置、紧急优先级及输液安全核对；错误选择扣分并显示复盘依据。
- 难度筛选：基础／进阶／高难；支持不联网完成模拟、评分本地保存、导出JSON。
- 保留 V1.2 全部原有查药、国家药监局核验入口、知识库、病历书写质控、化验单解读与疑难问答模块。

## 使用方法

1. 根据 `requirements.txt` 安装依赖，在项目目录运行 `uvicorn app.main:app --host 0.0.0.0 --port 8000`，用 Safari 访问已部署的 HTTPS 地址。
2. App 中打开“全真模拟接诊”，在“病例类型”选择**呼吸／消化／住院输液**，按难度筛选，点击“开始接诊”。
3. 问诊、查体、选择检查，随后选择诊断、用药策略、治疗计划。住院病历中需审核输液安全与医嘱，通过或退回相关医嘱。
4. 提交后查看评分、未完成核查、危险选择和资料来源，保存复盘笔记或导出报告。

### 病例数量说明

157份并非157种疾病。包含先前13例 + **36个新的诊疗主场景**，每个场景通过就诊阶段、年龄、体重、病房时间线和教学难度组合成4份变化版。这些变化版不能替代独立医学案例或真实生理仿真。

### 关于住院输液内容

模拟题重点是指征判断、低钠/液体过量、过敏反应、外渗、静脉炎、治疗升级、转口服、液体出入量和动态评估。没有生成可直接复制到医院HIS系统的儿童输液医嘱；体重相关液体类型、剂量、泵速及药物配伍必须依据本院制度和经审核的具体说明书由有资质人员核实。

### 数据与隐私

模拟全程使用虚构内容，不需 AI API；本地评分保存于浏览器 `localStorage`，未加密，可能被清理缓存删除。不要输入真实姓名、病案号、检验单或其他可识别患者资料。导出JSON同样未经加密，应妥善保管。

### 医学审校状态

**没有完成逐病例专业签审。** 关联资料链接是阅读/核对入口，并不证明每个题设、检验数值或答案已被原始指南逐句支持。部分非感染性消化外科情境只有背景资料，已显式显示待专科审校；医学参考按适用人群及本地规范复核后才能用于正规教学。

### 运行/测试状态

- 已通过63项Python自动化测试，所有前端JavaScript语法检查与加密备份冒烟测试。
- 390px离线模拟DOM交互测试检查了医嘱审核、评分与模拟学习记录；由于本环境限制本地浏览器访问，仍须iPhone Safari真机验收。


已完成单元与集成自动化测试，以及无联网条件下的模拟 iPhone DOM 交互测试；尚未完成真实 iPhone Safari 与医院网络真机验收。已知浏览器策略限制 localhost 自动导航，因此手机测试使用注入式离线DOM模拟，不能等同于实机验证。

更多说明见：`docs/病例目录与审校状态.md`、`docs/功能测试与医学限制.md`。

# V1.2 新增：全真模拟接诊（虚构儿科 OSCE 实训）

> 说明：这是模拟接诊交互，不是经过医学专家或国家考试机构认证的“真实临床能力评测”或生理仿真。所有病例均为**原创、虚构、无身份信息**；不得用真实患者数据测试。病例目前未完成中国儿科专家逐例审查。

### 使用

从 App `学习 → 全真模拟接诊` 或 `工具 → 全真模拟接诊` 进入。可按系统随机抽取 13 个固定、可重复的虚构病例。系统**隐藏答案**，由学习者逐步问诊、查体、下检查并选择最可能诊断、药物策略与处置。操作会推进模拟时钟；选择复评可看到预设病情变化文本。交卷后给出量化分数、应问未问的问题、危险选择、药物/治疗思路以及原始资料入口。分数本机保存，能导出 JSON。

### 设计与可复用开源项目

结合以下项目的**架构思路**自行开发原创实现，**没有直接复制其病例或源代码**：

- [Open Sim Lab](https://github.com/clay-good/opensimlab) — MIT，跨学科动态模拟与离线复盘；注意它自述并未经过直接临床使用验证。
- [Virtual Standardized Patient](https://github.com/igembitsky/virtual-standardized-patient) — MIT，固定患者事实与问诊分离、OSCE训练。
- [OpenLabyrinth](https://github.com/olab/Open-Labyrinth) — GPL-3.0，仅参考分支病例设计思想；未引用其GPL代码。

本项目没有引入这些项目的原始文件/第三方库，因此保留现有独立源码结构。

### 医学证据与边界

13例包括呼吸（普通感冒、CAP、支原体肺炎、细支气管炎、哮喘）、消化（急性腹泻脱水、肠套叠）、泌尿（发热性尿感）、过敏（过敏性休克、荨麻疹）、外伤（头部外伤）、急诊（热性惊厥）、新生儿发热。

证据入口逐例在 `web/simulation_cases.json` 的 `source_ids` 中列出。**中国资料**优先采用国家卫健委2025支原体肺炎指南、2020腹泻规范、中华儿科杂志2024 CAP指南；其他选题暂以国际学会或儿童医院路径作补充，明确标示**非中国指南**。选项为教学层面的药物策略，不提供未经审核的儿童注射剂量、复溶配伍或可执行处方。

### 实现原理

- `web/simulation_cases.json`：固定题库，包括家属问答、查体、检查报告、用药处置选项、评分点、模拟复评脚本和出处。后续可安全扩充。
- `web/virtual-patient.js`：纯浏览器脚本，**不调用 AI API**；为避免 AI 编造患者事实，开放式提问用有限关键词匹配；无法匹配时明确拒绝编造。
- iPhone 离线支持：首次 HTTPS 访问后由 Service Worker 缓存数据及代码；初次安装仍需要服务器。
- 学习评分是教学规则，**不是经过验证的 OSCE 量表**；病例信息也不是医学专家审核通过的处方路径。
- 时间模拟为**预设脚本**，没有实时生理参数推算，不可对真实病例预测。
- 本机评分保存于 `localStorage`；导出普通JSON**未加密**。不要填写真实患者的任何身份数据。

### 测试

`pytest -q` 包括原有回归测试和 V1.2 病例目录、题库答案一致性、来源、前端静态资源等新测试；额外 `node --check web/virtual-patient.js`。真机 Safari、医院网络与中国儿科专家审核仍未完成。

# V1.1 新增：医学证据逐条审校与说明书授权准备

本项目基于V1.0源码，不替换临床内容为AI生成结论。**本版新增的是逐条证据审计工作台，并非医疗专家审签。**

- App：学习 → 医学逐条审校。支持按领域、风险、缺来源检索、查看待审原文和候选来源、下载审核CSV。
- API：`/api/audit/summary`、`/api/audit/items` 和 `/api/audit/export`。没有匿名用户可调用的“审校通过”接口。
- 数据：`data/medical_audit.json` 为机器拆分出的待审清单，`docs/医学逐条审核底稿.csv` 和 `docs/儿科临床药典_V1.1_医学证据逐条审核工作簿.xlsx` 为供专业人员补证据和签审的工作底稿；请另存填写后的版本，不要将未经验证的个人填写内容直接导入正式App。
- 再生成：修改临床知识库后执行 `python tools/build_evidence_audit.py`，所有条目使用稳定ID与正文SHA-256支持版本比对。
- 专业审校：`docs/专业审校操作规程.md`、`docs/医学逐条审计报告_V1.1.md`。
- 授权采购：`docs/药品说明书授权询价与验收要求.md`，`docs/供应商询价函.md`。
- 质量底线：所有医学断言仍为待审核，所有儿童具体注射处方建议不可自动标记为临床可用。

# 中国儿科临床药典 V1.1 · iPhone 学习版（完整源码）

**交付日期：2026-10-29。** 本项目由 V0.6 升级，提供 iPhone Safari 可添加到主屏幕的中文 PWA，以及 Python FastAPI 后端。

> **重要边界：软件程序自动化与教学互动已通过指定测试；不是医学专家逐条审核通过的临床诊疗系统，不符合“直接给患儿开处方或自动签病历”的使用条件。** 本版本仅供虚构、可靠去标识化的医学学习材料使用。任何真实儿童诊疗/静脉给药均需本院批准的规范、对应厂家说明书、相关监护和有资质医务人员审核。

## 主要功能

1. **中国药品说明书查询**：已保留天聚数行和摩熵数科服务器适配；均需申请合法 API Key；未配置时不会捏造查询结果。国家药监局作为官方手动批准文号核对入口；没有虚构官方开放 API。
2. **儿科系统学习**：原有17个基础系统、89个专题，54条结构化常见病诊疗路径，呼吸、消化、泌尿、外伤、过敏、感染、新生儿和其他系统；全部属于待医学专家逐条审核的编辑内容。
3. **化验单与检查单**：155项指标解释、17类化验项目、67项报告术语、15类检查方式；支持数值、单位、报告参考区间核对，文本匹配及拍照裁切/可选自建OCR。不具备原始CT/胸片自动诊断能力。
4. **静脉输液学习**：14项原有静脉治疗安全专题、输注mL/h数学换算；新增13项静脉药安全核对练习（年龄、指征、剂型厂家、来源、过敏、体重、剂量单位、上限、肝肾功能、复溶配伍、输注、监测、双人核对）。只列缺漏，不声明处方安全。
5. **病历书写质控**：入院、首次病程、日常病程、门急诊初诊四类；本地筛查结构、时间、矛盾和书写建议，展示《病历书写基本规范》相关条款。可选DeepSeek教学二次审阅；不会自动审批、签名或凭空补写医疗事实。
6. **疑难问题/个人学习记录**：本地知识库检索和IndexedDB教学记录；可选配置AI服务进行匿名教学问答。自愿操作才发送AI或自建OCR请求。
7. **V1.0 新增25道循证学习题**：诊疗/病历/检验/隐私/用药核验等领域，每题配原始来源和易错点，提供错题复盘。出题属于编辑拟题，尚未经临床专家逐题评审。
8. **V1.0 新增来源与内容审校看板**：显示36条有来源链接的诊疗路径与18条缺少来源链接的路径；不把来源链接误当成内容完成医学审核。7个权威资料入口。
9. **V1.0 新增加密导入导出**：学习笔记和病历教学记录可用 AES-256-GCM + PBKDF2-SHA256（31万次）导出为加密JSON备份，支持密码解密及去重导入。注意：加密**只适用于导出备份文件**，本地 IndexedDB 并未由此加密。

## 启动与部署

### 本地开发 / 电脑预览

需要 Python 3.12+：

```bash
python -m pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000/`。未配置API仍可使用本地学习及病历规则检查；OCR需要服务器安装 `tesseract` + `chi_sim`、`eng` 语言包。

### Docker（包含中文Tesseract）

```bash
docker build -t pediatric-cn-v1 .
docker run --rm -p 8000:8000 --env-file .env pediatric-cn-v1
```

`.env` 从 `.env.example` 创建，绝对**不要**放入 `web/` 目录、Git仓库或发送给第三人。部署到可供 iPhone 访问的服务器时需要**HTTPS**，然后在 Safari 访问网址，使用“分享 → 添加到主屏幕”。

建议配置：

- `TIANAPI_KEY` **或者** `MOSENG_API_KEY`：中国药品说明书数据；商业接口请确认授权与字段完整性。
- `AI_API_KEY`、`APP_ACCESS_CODE`：可选 DeepSeek AI 教学审阅；后台须设置强访问码并限流。
- `OCR_ACCESS_CODE`：独立于 AI 访问码的匿名教学图片 OCR 访问控制。

**不配置以上 API 与服务也可运行离线学习内容**，但在线药品查询/AI识别不可用。
