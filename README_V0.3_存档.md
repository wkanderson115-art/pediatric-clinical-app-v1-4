# 儿科临床药典 · 中国版 V0.3（iPhone PWA）

> **开发原型，不是经过临床认证的诊疗软件。** 用于中国儿科临床学习、资料检索和个人复习。不得据此自动开医嘱、计算个体患儿可执行处方，也不能替代院内诊疗规范、药品说明书或带教医师审核。

## 本次交付范围

- **17个儿科专题系统、89个疾病/问题学习条目**，覆盖呼吸、消化、泌尿/肾脏、过敏免疫、感染、新生儿、神经、心血管、内分泌代谢、血液、急诊重症、生长保健、皮肤、骨关节风湿、眼耳鼻喉、临床药学和疑难问题。每条含「临床识别、检查与鉴别、处理与用药原则、紧急警示、常见误区」。
- **针对呼吸系统强化12条专题**：支气管肺炎、肺炎支原体肺炎、病毒性肺炎、细菌性肺炎、毛细支气管炎、儿童哮喘、反复喘息、急性喉炎、百日咳、慢性咳嗽、气道异物和胸腔积液/脓胸。
- **疑难问题询问**：默认检索本地资料库（不上传问题）。如由部署者配置 `AI_API_KEY` 和 `APP_ACCESS_CODE`，可由用户主动切换为 AI 文字辅助分析，勾选明确同意后才向第三方发送匿名问题。
- **自动学习日志**：提问、返回内容、时间、分类、关联专题和证据限制写入 iPhone 浏览器 `IndexedDB`；可再次提问、编辑自己的复习笔记、关键词搜索、导出/导入 JSON 备份或单条删除。
- **中国药品说明书**：保留天聚数行、摩熵数科的后端适配；不同企业、剂型、规格与批准文号的内容不能混用。需要正式授权的数据 API Key 才可真正联网检索药品。
- **药品注册核验**：国家药监局公开查询站 `https://datasearch.nmpa.gov.cn/` 是**跳转和人工核验**，不是已接通国家药监局官方数据库 API。摩熵批文索引属于第三方信息。
- **剂量数学练习**：手动输入已核对的 mg/kg/次 或 mg/kg/日、体重、频次与单次上限，不内置自动处方规则。
- 安装到 iPhone 主屏幕后为 PWA；预先访问过且保留离线缓存时可阅读静态学习库。浏览器离线缓存不包含实时药品说明书、AI查询结果或服务器数据。

### 关于学习内容的质量

这89条是**可扩展的入门与进阶学习提纲**，**不等于儿科全部专业教材**，也**不是89份已获专业审查的官方指南**。部分主题有中国官方或学会文献入口；其余条目明确标注“编辑学习提纲，尚未经临床专家逐条审核”。相关链接是追溯资料的入口，并不表示每一条摘要的每句话都已逐句验证。继续扩充时，应纳入准确版本日期、专家复核和修订记录。

## 快速启动（Windows 10 / macOS / Linux）

需要 Python 3.11+：

```bash
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

电脑打开 `http://127.0.0.1:8000`。

iPhone 无法直接访问电脑 `127.0.0.1`。同一Wi-Fi下可在电脑监听局域网地址并打开 `http://电脑局域网IP:8000` 进行开发预览，但若要正式“添加到主屏幕”、离线安装及安全使用，应部署到**具有 HTTPS 和访问控制**的受信任服务器。不要在没有认证的公网直接暴露含 AI Key 的服务。

## 设置中国药品说明书API（可选）

从 `.env.example` 复制服务端环境变量，或在运行命令前在环境中设置：

```text
DRUG_PROVIDER=auto
TIANAPI_KEY=申请到的天聚数行密钥
MOSENG_API_KEY=申请到的摩熵说明书/批文权限密钥
```

`auto` 优先摩熵，其次天聚数行。实际查询权限、规格字段和额度以相应服务商的正式文档和合同为准。未填写 Key 时，查药页面会明确提示“未配置”，不会提供假药品记录。中国药监局官网的查询仍需人工操作。

## 设置AI疑难问题分析（可选）

支持经过限制的两个官方兼容接口地址：

```text
AI_API_URL=https://api.deepseek.com/chat/completions
AI_MODEL=deepseek-chat
AI_API_KEY=服务端的DeepSeek API密钥
APP_ACCESS_CODE=至少8位、自己设定的随机访问码
```

如果采用 OpenAI 官方兼容端点，使用 `https://api.openai.com/v1/chat/completions` 并配置当前可用的对应模型及 Key。**本项目不使用 ChatGPT 订阅额度来调用 API。**

- `AI_API_KEY` **只能在服务器环境变量中设置**，不要写入前端、分享给他人，也不要上传 GitHub 公开仓库。
- `APP_ACCESS_CODE` 不是供应商 API Key。在 iPhone 问答页面选择 AI 后手工输入；服务器会校验此访问码，未授权返回403。
- AI回答不是实时联网文献检索，也不会自动验证医学指南全文；其内容会标注“AI生成未审核”。不提供个体患儿的自动处方。
- **默认本地模式绝不向第三方AI发送问题**。切换AI也必须主动勾选外部发送同意；明显疑似身份证号、手机号或住院号的文本会被拒绝，但自动识别不能覆盖所有个人信息。
- 由于没有账号管理和传输审计系统，**不能用于真实患者电子病历或保存个人身份信息**；不适合医院正式部署，除非追加合规认证、访问审计、数据加密及权限管理。

## iPhone添加到主屏幕

1. 把服务端部署到有 HTTPS 的地址。
2. iPhone 使用 Safari 打开网页，确认学习库加载正常。
3. 在分享菜单中选择「添加到主屏幕」。
4. 提问和学习记录只保存在当前设备的浏览器本地数据库；清理浏览器数据可能使其丢失。
5. 定期到「记录 → 导出JSON备份」，文件未加密，应妥善保管；可在另一设备通过「导入备份」恢复（属于手工迁移，非自动云同步）。

## 疑难问题操作

1. 进入「提问」，使用匿名信息描述罕见症状、非典型病例或用药疑问。
2. 选「本地知识库」会返回相关条目和来源，若未收录会明确说无法解答；该模式不调用AI。
3. 选「AI辅助分析」需要已配置AI Key和访问码，勾选同意后发送；系统输出鉴别思路、红旗征象和待核对证据，**不自动开药**。
4. 一次提问会自动形成一条记录，AI失败也会记为「待复查」（不伪造答案）。到「记录」追加带教老师意见、复习要点，随时搜索、导出、导入或删除。
