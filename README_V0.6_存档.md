# 儿科临床药典 V0.6 — 中国版 · iPhone PWA

本项目基于 V0.5 源码升级，保留中文查药、国家药监局人工核验、儿科学习库、疑难问答与学习记录、病历书写质控、155项检验指标、67个检查报告术语及输液安全学习模块。新增了**38条诊疗路径（累计54条）**和**去标识化教学报告的拍照裁切／可选OCR**。

> 使用边界：仅供医学教育与匿名模拟病例学习。当前所有疾病路径均未完成逐条临床专家审校，不是临床决策支持系统，不直接形成治疗医嘱。不能基于OCR识别值、模型回答或未核实说明书给患儿用药。

## 新增的临床学习

在 **学习 → 系统诊疗路径** 或 **工具 → 诊断与治疗学习路径** 中查看，可根据类别筛选和全文搜索。

54条路径覆盖呼吸（细菌性/病毒性肺炎、支原体、哮喘、哮吼、毛细支气管炎、百日咳等）、消化（急性胃肠炎、细菌性肠炎、阑尾炎、肠套叠、便秘等）、外伤（创伤伤口、头部外伤、骨折扭伤、烧烫伤、动物咬伤）、泌尿（尿路感染、肾盂肾炎、肾炎、肾病综合征、遗尿）、过敏（荨麻疹、过敏性休克、食物/药物过敏、湿疹、鼻炎）、新生儿、神经、感染、心血管及耳鼻咽喉等。

新增条目的学习字段：年龄提示、临床识别、推荐评估和检查、鉴别、治疗原则、**用药选择与核对原则**、输液/注射必要性、复评、其他/非典型情况、危险信号、参考来源。每条可点击“遇到其他情况？提问并记录”，跳转到现有疑难学习记录模块。

**用药规则说明**：新增内容重点说明何时需要抗菌药、何时优先口服、何时转急诊/专科，并非未经审核的具体 mg/kg 处方模板。详细儿童剂量需要中国批准说明书/相应指南/医院药学审查后才能可靠使用。

## iPhone 拍照识别：化验单与检查单

1. 用 iPhone Safari 打开部署后的 HTTPS 地址，进入 **工具 → 拍照识别与化验单全解** 或 **拍照识别影像/心电/超声报告**。
2. 选择**虚构、教学或充分去标识化**的报告照片；网页只加载本地预览，默认不上传。
3. 使用四个百分比输入框，裁掉顶部、底部、左侧和右侧，不得上传含姓名、二维码、条码、身份证、住院号、手机号或其他可识别信息的报告。确认图像预览展示的裁切区域。
4. 若自建OCR服务器已设置访问码：主动勾选本次上传同意，输入单独的 `OCR_ACCESS_CODE`，点击“一次性上传并提取文字”。OCR只对**报告文字**进行识别，不分析CT或X线原始图像。
5. 得到文本后，对照原图纠错（特别是小数点、数值、单位、参考范围）。化验单可提取候选项目并复制到多项报告框；**软件不自动猜测参考范围**，也不自动诊断。检查单把纠错后的文本送入已有术语解读模块。
6. 如果没有部署OCR，可在 iPhone 系统照片 App 用“实况文本”复制匿名教学报告文字，再粘贴到文字框，**不需要上传图片**。

### OCR部署

OCR不依赖付费AI API：使用自建服务器上的开源 Tesseract OCR。必须提供**自建服务器**；该OCR不是纯端侧识别，也不是国家药监局数据接口。OCR访问码由你设置，与药品API Key和DeepSeek Key不同。

```bash
# 任选其一，推荐 Docker 安装方式（含中文OCR）
docker build -t paediatric-cn-v06 .
docker run --rm -p 8000:8000 -e OCR_ACCESS_CODE='请换成高熵随机长访问码' paediatric-cn-v06
```

本机开发环境中也可安装 Python 3.12+、依赖和简体中文 Tesseract：

```bash
pip install -r requirements.txt
# Linux 例子：sudo apt install tesseract-ocr tesseract-ocr-chi-sim tesseract-ocr-eng
export OCR_ACCESS_CODE='请换成高熵随机长访问码'
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

通过 `GET /api/ocr/status` 查看OCR引擎和访问码配置是否可用（不会返回密钥）。`POST /api/ocr/recognize` 仅支持经过前端裁切的JPEG/PNG/WebP（≤8MB），使用表单字段 `image`、`consent=yes`、`report_type=labs|exams`、头 `X-OCR-Access`。未同意或没有正确访问码时拒绝请求。

**隐私边界**：OCR服务端不持久保存报告、不写入数据库、不主动发送到AI服务商，但图像会在服务器上处理，并可能产生工具运行期间的临时文件；服务器管理员应确保访问日志不记录请求体、禁用第三方请求抓包、及时清理异常残留临时文件。正式医院病历或未去标识化患者照片**不应上传到本教学原型**。正式生产需要医院授权、安全评估、访问审计、端到端传输安全与符合法规的数据治理。

## 其他 API

- 中国药品说明书：`TIANAPI_KEY` 或 `MOSENG_API_KEY`，相关联的国家药监局网站仅作为**官方人工核验入口**，没有假定存在官方开放接口。
- AI疑难问题：`AI_API_KEY` + `APP_ACCESS_CODE`（需要明确同意上传去标识化学习内容）。
- OCR拍照：`OCR_ACCESS_CODE` + 本机Tesseract引擎；独立于以上两类接口。
- 不配置任意外部API，原有本地学习、病历结构质控和手动报告解读仍可用。
