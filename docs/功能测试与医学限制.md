# V1.3 功能测试与医学限制

## 技术验证

- `pytest -q`：60项测试通过（涵盖现有基础功能、病例结构、一致性、接口静态资产、医嘱审核字段）。
- `node --check web/virtual-patient.js`：JavaScript语法检查通过。
- 390px 宽模拟 iPhone 离线DOM交互：按难度抽取住院病例、显示6个住院记录区、显示静脉核对题、执行问诊/查体/检查/诊断/用药及治疗选择、提交评分与复盘，完成。
- 浏览器模拟交互记录：没有捕获到JavaScript页面异常，也没有横向溢出。
- 服务端 GET /：FastAPI TestClient 返回200。首次部署到真实HTTPS设备尚待验收。

## 未完成或未经过验证

1. 未在用户真实 iPhone Safari 或 App Store 中测试安装、摄影、持久存储和离线恢复。
2. 未完成36个新增主场景或144个情境变体的医生逐例医学签审；检验值、病情变化为人工编写的模拟数据。
3. 模拟病情变化不是临床生理动力学模型，不可预测真实患者反应。
4. 治疗选择不构成执行医嘱，尤其没有对儿童静脉药物剂量、浓度、相容性和输注速度做生产环境验收。
5. 关联来源是主题级参考入口，有些来源是国际指南或相关领域背景资料，不能据此声称全部案例符合最新中国临床指南。

## V1.3 最终验证补充（2026-10-29）

- Python `pytest -q`：**63 项通过**（覆盖既有查药/学习/审校、病例数量结构、医嘱风险选项、数据一致性）。
- 逐个执行 `node --check web/*.js`：无语法错误。
- `node tests_client/secure_backup_smoke.cjs`：加密/解密/密码错误/重复数据防护通过。
- Chromium 内存 DOM + 模拟 390px iPhone 布局：住院分类及难度过滤、随机开始、问诊、查体、检查、审核模拟医嘱、评分、模拟本地记录均可交互，捕获页面脚本错误 **0**，无横向溢出。
- 由于当前运行环境限制本地 HTTP 浏览器导航（ERR_BLOCKED_BY_ADMINISTRATOR），上述浏览器测试使用注入式 DOM 与模拟 localStorage，**不等于真实 iPhone Safari 的部署测试**；真实手机缓存、网络及权限行为尚待确认。
- **医学专家逐例审校未完成**：源链接已与部分情境相关联，但评分规则、诊断标准、虚构化验数值、用药与输液方案不应视为通过临床验证。非中国资料为辅助参考，不能替代本院标准。
