# 中国儿科医学内容机器审计报告 V1.1

**生成日期：2026-10-29 | 审核性质：程序自动拆条与证据追溯，不是专家医学审校。**

## 一、总体发现

- 共拆解 **2155** 个独立医学学习文本条目；其中 **702** 条挂有候选来源入口，**1453** 条尚无独立来源入口。
- **医学专家逐条签审：0条**；未获取专家身份和临床药师签名，不会将“已找到来源”升级为“审核通过”。
- 记录有稳定条目 ID、原文 SHA-256、归属分类和自动风险优先级。风险分级只是**审阅队列的启发式排序**，不是临床严重程度判断。

## 二、最重要的内容缺口

1. **注射药物**：现有内容主要是安全核对原则，尚无依具体中国批准文号/制剂版本验证的药品配制、输注速度与儿童剂量规则；不得直接给出可执行医嘱。
2. **检验指标**：现有155项是解释性条目，其中106项没有独立来源入口；既有链接也未逐项对照适用年龄、检验方法和单位。不能把所附标准扩展为不在其项目范围内的全部检验。
3. **影像检查术语**：67项术语全部需相应专科审核；“影像词典”不能替代阅片、诊断或风险分层。
4. **诊疗路径**：54条中的18条没有单独来源链接；其他条的来源多为**文献入口级**，尚未定位到页码、段落和适用人群。
5. **题库与学习摘要**：候选来源存在但逐句对应性、题目答案是否符合最新规范尚未得到专家逐条确认。

## 三、建议的审校闭环

1. 医学编辑定位每条原始证据的**具体节号/页码/段落**，并附原文对照或公开合法引用段落。
2. 先由儿科医生复核诊断与治疗逻辑；注射/高风险药另由临床药师审核；检验/影像内容交相应专科核查。
3. 对每条形成：适用年龄、排除条件、证据发布日期、审校结果（通过/需修改/不适用）、审核人和时间。
4. 冲突内容要先修订并重新提交，不得保留旧版“已审核”状态；通过SHA-256追踪改动。
5. 所有高风险条目由两位适格审核者独立签审后才可考虑在教学版本中标注为“专业已审”。
6. 病历书写依据须同时匹配国家2010年基本规范及实际医院病历管理细则，不以AI判断替代临床审核。

## 五、交付文件与使用方法

- `data/medical_audit.json`：App读取的逐条审校索引。
- `docs/医学逐条审核底稿.csv`：可用Excel/表格软件打开，补充 `evidence_locator`、`reviewer_name`、`review_date` 等栏位。
- `tools/build_evidence_audit.py`：从当前学习库重新生成记录；不可用于自动判断医学正确。
- `docs/药品说明书授权询价与验收要求.md`：采购合同与API试用清单。
- `docs/供应商询价函.md`：可复制发送的商务沟通模板。
- App首页学习区 → **医学逐条审校**：支持筛选、检索、查阅原文和下载底稿。
