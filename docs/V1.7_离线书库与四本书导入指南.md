## 二、电子版获取

### A. 正版电子渠道（页码与清晰度可靠，优先）

- 科学文库（科学出版社官方电子书）：[临床检验报告解读](https://scibook.sciencereading.cn/shop/book/Booksimple/show.do?id=B58E3B74FBD8245A0E053010B0A0A2A01000)

- 微信读书 / 京东读书 / 掌阅：部分医学工具书有电子版
- 超星/读秀（需机构账号）：可按 ISBN 定位到馆藏电子版
- 图书馆 OPAC 参考（用于核对版次与 ISBN）：[国防科大 OPAC：石同才](https://libopac.nudt.edu.cn/opac/search?searchWay=author&q=%E7%9F%B3%E5%90%8C%E6%89%8D)、[泰山图书馆：齐建光](http://202.194.232.137:8080/opac/openlink.php?author=%E9%BD%90%E5%BB%BA%E5%85%89)、[实用儿科药物剂量速查手册（第5版）书目](http://yuntaigo.com/book.action?recordid=a2tta3pvZmM2NjY=)

## 三、导入

```bash

  --id zhufutang9a --title "诸福棠实用儿科学（第9版·上册）" \
  --authors "王天有 申昆玲 沈颖" --publisher "人民卫生出版社" --year 2024 --edition 9

python tools/import_library.py data/library/raw/zhufutang9b.pdf \

  --id lab_report --title "临床检验报告解读" --authors "石同才" --publisher "科学出版社"

python tools/import_library.py data/library/raw/peds_resident.pdf \
  --id peds_resident --title "儿科住院医师手册" --authors "齐建光 闫辉 张欣" --publisher "北京大学医学出版社"
```

## 四、PDF 文本抽取依赖

| 情况 | 处理 |
| --- | --- |
| 文字版 PDF | `python -m pip install pypdf` 即可，导入工具自动调用 |
| 已有 Poppler | 安装 `pdftotext` 也可（工具会回退用它） |
| 扫描版 PDF | 先 OCR：`ocrmypdf --language chi_sim input.pdf output.pdf`，或在 iPhone 用「实况文本」导出 txt 再导入 |
| 加密/权限受限 PDF | 用你有权使用的版本重新导出，工具不做解密 |

## 六、边界

- 书籍版权归原作者与出版方；项目不包含、不分发电子书，只提供导入与检索。
- 检索是原文子串匹配，不是语义检索；命中片段不能作为用药或诊断依据，须回原文核对。
- 书库内容与项目内的教学条目（药典/参考区间/路径）是两套数据，互不覆盖。
