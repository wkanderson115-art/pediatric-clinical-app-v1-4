# 中国药品说明书数据授权申请与验收需求书（用于供应商沟通）

**项目名称**：儿科临床药典 · 中国版 iPhone 医学学习应用  
**产品定位**：中国儿科临床学习、指南阅读、药品说明书查询与匿名教学病例训练；不自动开具医疗处方或替代医疗机构审方。  
**申请人**：待申请方补充（本文件不是合同，也不代表已经取得任何授权）。

## 一、申请接口

1. 中国药品说明书**列表与详情查询**：按通用名、商品名、剂型、规格、生产企业、上市许可持有人、批准文号搜索。
2. 中国药品批准文号与注册信息辅助检索：独立标记为第三方数据；国家药监局官网供手工复核。
3. 可选：说明书更新记录/药品修订公告；对儿科治疗可能影响用药限制时提供变更通知。
4. 可选但需独立报价：注射剂配伍库、药物相互作用库、特殊人群用药与指南数据库；不得与普通说明书授权混同。

## 二、必须提供的字段和质量指标

- 药品唯一主键、中文通用名、商品名、剂型、规格、含量/单位、给药途径；生产企业及上市许可持有人。
- 国药准字等批准文号、注册状态、批准信息来源、说明书修订日期、数据采集日期、最后更新日期。
- 完整说明书段落（适应证、用法用量、儿童用药、禁忌、注意事项、药物相互作用、不良反应、药理、贮藏），允许明确标记缺失。
- 支持区分同通用名下不同厂家/规格/注射剂，不通过药品名称直接合并不同批文的说明书。
- 保留来源版本，更新后能定位变动章节、可回溯旧版和返回原文证据；不能在客户端悄悄替换剂量规则。
- 药品数据的儿科年龄限制、体重用量、最大剂量等字段，供应商若没有可靠结构化数据，应返回“不提供”而非AI推断。

## 四、建议试用数据集（不请求任何真实患者信息）

按名称查询并由供应商返回各生产企业、批准文号、剂型、说明书修订日期、儿童用药章节完整度：

- 呼吸抗菌：注射用头孢曲松钠、注射用头孢噻肟钠、注射用氨苄西林钠、注射用阿奇霉素、注射用美罗培南。
- 复杂感染：注射用万古霉素、注射用头孢他啶、注射用哌拉西林钠他唑巴坦钠。
- 哮喘/重症：注射用甲泼尼龙琥珀酸钠、地塞米松磷酸钠注射液。
- 抢救/过敏：盐酸肾上腺素注射液、盐酸多巴胺注射液。
- 补液相关：氯化钠注射液、葡萄糖注射液、氯化钾注射液。
- 对照剂型：阿奇霉素干混悬剂与注射用阿奇霉素；头孢曲松不同厂家及不同规格。

上表仅是用于核验**数据覆盖率、剂型和适应证差异**的测试关键词，不代表儿童应使用其中任一药物。

## 五、试用验收方法

1. 每个查询至少记录：`request_name`、`provider_item_id`、`approval_number`、`manufacturer`、`dosage_form`、`specifications`、`revised_date`、`sections`、`data_source`、`fetched_at`。
2. 人工挑选多厂家、多规格、口服与注射共存的记录，检查是否发生不同说明书串换。
3. “儿童用药”和“用法用量”缺失时必须显示为缺失，不能编造或自动填入成人用法。
4. 校验禁忌、适用年龄、新生儿限制和已知警告章节是否完整；数据质量问题提交供应商复核。
5. 医师+临床药师签审之前，只允许标记“第三方说明书查询结果，未完成专业审校”。
6. 接口性能、限流和合同许可需同时通过，技术返回HTTP 200不等于数据可用或商业授权已生效。

## 六、已确认的公开接口信息（2026-10-29核对）

- 摩熵数科：`POST https://srv-openapi.bcpmdata.com/pharma/general/v1/drug_instruction/list`，文档提供批准文号、企业、药名和页码等检索字段，并提供说明书章节和修订日期等返回字段；服务一般默认每接口1次/秒、100次/日，具体可合同调整。[公开文档](https://open.bcpmdata.com/api/173.html) · [接入说明](https://open.bcpmdata.com/api/1.html)
- 天聚数行：`https://apis.tianapi.com/yaopin/index`，公开文档仅列药品名称与内容等基础字段；仅适合初步覆盖率试验，不能默认达到按批准文号核验的要求。[公开文档](https://www.tianapi.com/apiview/134)
- 国家药监局： [官方公开查询](https://datasearch.nmpa.gov.cn/)；本项目未取得官方公众可调用的药监局数据API。
