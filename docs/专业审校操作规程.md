# 医学专业审校与发布门禁操作规程

**目的：**为中国儿科临床教育内容提供可追溯的质量控制。此文档不能代替医疗机构的医疗质量安全管理制度。

## 参与角色

- **医学编辑**：拆分医学内容、关联指南版次、定位原始章节及页码；不得代替临床签审。
- **儿科医师**：核实临床诊断、鉴别、住院指征、治疗选择与患儿年龄适用范围。
- **临床药师**：核实药名、批准文号、剂型规格、适应证、年龄限制、每日和单次剂量、配伍、输注、监测等高风险药学内容。
- **临床检验、影像等专科审核者**：核实本专业参考范围、计量单位、技术限制和诊断边界。
- **病历质控人员**：对照《病历书写基本规范》和实际医院细则确认文书规则适用性。

## 逐条审核的填写方法

1. 从 `医学证据逐条审核工作簿.xlsx` 或 CSV 选一条，先确认`claim_id`和`content_sha256`。
2. 查看候选来源，并在 `原文节号或页码` 栏填写能够支持该结论的**确切位置**；如来源不支持，标“证据不足”，并补充更合适证据。
3. 评估**适用年龄、特殊人群、检验方法、适应证、诊疗条件和信息是否已过期**；不能直接照搬成人规范。
4. 审核结论只允许“符合原文 / 需修改 / 不适用 / 证据不足”，不得用软件自动生成的“已审核”替代签名。
5. 对诊疗和药物P0条目采用儿科医生与临床药师双复核；审查应有可核验身份、日期和修改记录。
6. 教学内容修改后，对比正文SHA-256；正文变更必须撤回旧版签审并重新审核。
7. 经过医院或专业机构的最终发布流程，方可把经过审查的内容导入正式教学库。

## 自动化可以做和不能做

**可以**：找缺失来源、定位术语、识别明显单位或字段缺失、生成审核待办、给出可能冲突的线索、跟踪文字变更。

**不能**：保证诊疗方案、剂量或说明书真实准确；自动签署执业医师/药师意见；将第三方数据包装成国家药监局官方认证；对真实患儿直接产生处方或最终医疗决定。

## 临床使用与发布门禁

- 本教学版固定为`医学专家已签审：0`，直到外部真实专业审核完成；网页不提供匿名编辑“通过”操作。
- 商业授权未书面确认，不展示未经许可的批量说明书全文。
- 在任何真实患者数据场景部署之前，先获得相应机构批准、隐私合规及软件监管评估。
