# 儿科临床药典 · 中国 iPhone PWA · V0.4

> **用途和边界**：中国儿科临床学习和匿名教学病历书写质控原型；**不是**医院正式病历系统、医生签审系统、医疗器械或自动临床决策系统。数据库条目是编辑性学习材料，**未进行逐条医学专家审核**。所有给药和诊疗必须依照中国现行批准说明书、适用的临床指南和所在机构流程。

## 本次在 V0.3 基础上新增

1. **深入的儿科诊疗学习**：保留原有17个学科系统与89个基础专题，另增16条结构化诊疗学习路径（重点有支气管肺炎/儿童社区获得性肺炎、支原体肺炎、病毒肺炎、喘息、急性胃肠炎、肾盂肾炎、过敏性休克等），每条含年龄、临床表现、鉴别、检查、诊治、输液审查、复评、危险征象和参考来源。
2. **检验报告解读**：26个检验指标说明。用户**自行**填写报告对应项目的参考上下限、年龄（月）和检测值，进行高低数值判断。App没有凭空套用单一的成人数值区间，更没有对异常结果自动诊断；年龄层和检测方法要由医院实验室核实。WS/T 780—2021仅覆盖部分28天—18岁儿童生化项目，不能替代所有检验。
3. **静脉治疗学习**：14项学习与核对主题，包括指征、液体类别、稀释/相容性、给药浓度、输注速度、静脉通路、感染控制、电解质、治疗监测；另提供“**已知体积与时间** → mL/h”的纯数学换算。**不自动配药、不推荐处方或输液量。**
4. **病历书写质控（核心）**：支持匿名教学用的住院入院记录、首次病程记录、日常病程记录、门急诊初诊记录。**离线本地**检查常见结构缺项、主诉缺少时长、过敏史冲突、体温/发热冲突、生命体征不完整、输入时间间隔与国家规范可能冲突等。每个问题给出原文线索、修改建议和规范线索；提供四类**不能自动填入未证实事实**的空白模板。
5. **可选AI二次审阅**：必须先做本地审阅，逐项确认文本已去身份标识，勾选同意并输入服务端 APP_ACCESS_CODE；服务器配置 AI_API_KEY 后才发送至支持的官方AI API。AI只返回辅助质控意见，**不允许自动盖章、签名、审批通过，不能自行编造临床事实。** 未配置API时可正常使用纯离线本地规则质控。
6. **记录保存与导出**：病历质控后须主动点击保存，方存于本机 IndexedDB，支持恢复、删除、JSON备份（备份**未加密**）；保留原有疑难问题笔记和药品说明书查询与国家药监局人工核验入口。

## 医疗记录隐私红线

- **只使用虚构案例或已获得合适许可、彻底去标识化的教学资料**。不要将真实病历或患者的可识别信息粘贴入 PWA，更不要未经授权发送第三方 AI。
- 自动身份信息检测只覆盖若干常见模式，**无法保证真正完成匿名化**。服务器只负责显式批准后的AI转发，默认不保存问题正文；但网络服务商仍可能按照自己的政策处理请求。
- 浏览器IndexedDB为**未加密本地存储**，不适合保存受监管的临床患者数据。此App不满足医疗机构电子病历要求的全部身份认证、审计追溯、授权访问、存档和电子签名要求。
- 不允许通过这个App直接编辑医院HIS/EMR、签发医嘱、生成正式病历审核意见或替代带教医生/病案质量管理部门。

## 运行方式

电脑（已安装Python 3.11+）运行：

```bash
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

电脑浏览器访问 `http://127.0.0.1:8000`。Docker部署可使用现有Dockerfile和云平台配置HTTPS。**iPhone 无法通过自己的127.0.0.1访问电脑服务。** 需要部署至可信HTTPS域名，再在iPhone Safari中打开，选择“共享/添加到主屏幕”。

Python环境变量可以从 `.env.example` 开始配置（部署平台配置环境变量；`uvicorn` 不自动读取.env，若要本地读取需另行使用dotenv或运行环境中注入）。

### 选配真实API

- 中国说明书：`TIANAPI_KEY`；或获商用授权的 `MOSENG_API_KEY`。若不配置，会显示未启用联机说明书查询。
- AI辅助审阅：`AI_API_KEY`、`AI_MODEL`（默认`deepseek-chat`）、`AI_API_URL`（只支持官方DeepSeek/OpenAI HTTPS地址）、`APP_ACCESS_CODE`（至少8位）。**不配置就只能使用本地规则质控和离线检索**。
- 国家药监局：**官方网页人工核验**，不是公开API直连；不要误认为第三方批文结果就是药监局实时证明。
- AI Key与说明书Key仅存后端，不写入前端。
